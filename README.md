# 独孤九剑 · 破招台工作台

> 以史为鉴，破工作与生活的招。一个把「独孤九剑」九式方法论落进日常待办、收支、习惯与复盘的个人效率工作台。纯前端、零依赖、零构建，数据存在你自己的浏览器里。

---

## 一、项目简介

「破招台」借金庸武学「独孤九剑」的**破招**思路——面对困局，先辨招、定式、明约束，再决定攻哪一手——来做个人效率管理。它把抽象的方法论拆成六个可操作的模块，让情绪劳动变成**可复盘、可积累**的招数。

- 不是又一个 Todo 应用，而是一套「遇到问题 → 系统辨招建议 → 落记录 → 复盘归档」的闭环。
- 内置 **独孤九剑九式方法论知识库**（总诀式、破剑式、破刀式、破枪式……），含白话转译、识别信号、行动模板与现代迁移场景。
- 数据完全本地化：使用浏览器 `localStorage`，无需账号、不上传云端；并支持 JSON / 加密（AES-GCM）备份与合并导入。

本项目由「资料库」中发布的单文件工作台**整理、重构并优化目录结构**而来：在不改变任何功能与交互的前提下，将 1300+ 行单文件拆分为职责清晰的多个模块，并始终保证「可直接运行」。

## 二、功能特性

| 模块 | 招式 | 能力 |
| --- | --- | --- |
| **今日要务** | — | 逾期未完成自动标红；昨日未了自动顺延；双场景合并视图；底部展示「本周记录量 / 最长连续」北极星指标 |
| **破招台** | 核心 | 描述困局 → 系统依九式方法论按关键词匹配度给出建议招式（含命中信号）→ 选招 → 落记录 → 可归档为待办跟进；手动选招兜底 |
| **待办 · 总诀** | 总诀式 | 按场景 / 招式过滤；优先级；完成态切换；统计卡（总数 / 已完成 / 高优先级未了） |
| **收支 · 破剑** | 破剑式 | 本月收支、结余、预算进度；支出分类环形图 + 图例；按场景过滤（国内习惯：支出红、收入绿） |
| **习练 · 破气** | 破气式 | 习惯打卡、连续天数、近 35 天热力图；达标里程碑提示（7/21/30/50/100/200 天） |
| **心法 · 九剑** | 九剑 | 每日按年内第几天轮换一式作为「今日心法」；九式全量卡片（心法 / 白话 / 步骤 / 标签 / 现代迁移）；可收藏 |

**通用能力**

- 🧩 **双场景**（工作 / 生活 / 交织）贯穿待办、收支、破招，按需过滤。
- 💾 **备份与恢复**：明文 JSON 导出、AES-GCM 加密备份（需密码，零依赖 Web Crypto）、埋点数据导出（JSON + CSV）。
- 🔀 **合并导入**：按条目 ID 合并，导入不会丢失已有数据。
- 🎁 **示例内容包**：一键载入「职场破招 / 生活破招」双场景示例，降低冷启动门槛。
- 🪶 **零依赖、零构建**：纯 `localStorage` 持久化，内联 SVG 图标与图表，无任何第三方库。
- 📱 **响应式**：桌面与移动端自适应。

## 三、安装步骤

本项目**无需安装任何依赖、无需打包工具**。你有两种运行方式：

### 方式一：直接打开（最简单）

双击 `index.html`，用浏览器打开即可。由于采用 classic `<script>`（非 ES Module），即使通过 `file://` 协议打开也能正常运行。

### 方式二：本地静态服务器（推荐，避免个别浏览器对本地文件的限制）

任选其一，在项目根目录执行：

```bash
# Python 3（自带，无需安装）
python3 -m http.server 8080

# 或 Node（若已装 npx）
npx serve .
```

然后浏览器访问 `http://localhost:8080`。

### 部署到任意静态托管

直接把整个目录（含 `index.html`、`styles.css`、`src/`）上传到 GitHub Pages、Vercel、Netlify、Cloudflare Pages 等任意静态托管即可。

> 💡 关于加密备份：AES-GCM 加密依赖浏览器 `window.crypto.subtle`，仅在 **https 或 localhost（安全上下文）** 下可用。若在不安全上下文打开，`导出加密备份` 会自动降级为明文 JSON 备份并提示。

## 四、使用方法

1. **首次打开**：会自动注入一份演示数据，先感受各模块；点开右上角「数据 · 备份 → 载入双场景示例」可加载更丰富的职场 / 生活示例。
2. **破招台（核心）**：
   - 选场景 → 在文本框描述当下困局（越具体越好）→ 点「辨招 · 看看用哪一式」。
   - 系统按九式关键词命中度排序给出建议招式与行动模板；可直接「用此招落记录」，或下拉手动选招。
   - 落记录时可选择「归档为待办跟进」，自动生成一条待办。
3. **待办 / 收支 / 习练 / 心法**：在各面板按提示录入即可，列表与统计会实时刷新。
4. **数据备份（重要）**：右上角「数据 · 备份」抽屉中——
   - `导出 JSON 备份`：明文全量备份。
   - `导出加密备份`：设置密码后导出 `.dg9j` 文件（忘记密码无法还原，请牢记）。
   - `导入恢复`：选择此前导出的文件，按 ID 合并导入，不丢已有数据。
   - 新增满 20 条记录时会温和提醒你导出备份。
5. **清空**：抽屉底部「清空全部数据」可一键重置（二次确认）。

## 五、目录结构

```
dugu-jiujian-workbench/
├── index.html          # 页面骨架（语义化标签，已剔除平台注入的冗余属性）
├── styles.css          # 完整样式（宣纸 / 朱砂 / 墨绿 主题，含响应式）
└── src/
    ├── data.js         # 常量与知识库：LS_KEY、SCENE_LABEL、九式 MOVES/MOVE_MAP
    ├── util.js         # 工具层：日期/格式化/埋点/导出辅助/AES 辅助
    ├── charts.js       # 内联 SVG 图表与图标：环形图/图例/热力图/勾选/删除/心形
    ├── store.js        # 数据层：全局状态、localStorage、示例、合并导入、清空、导出/加密
    ├── ui.js           # UI 层：同步状态/横幅/数据损坏兜底/抽屉/场景分段控件
    ├── app.js          # 主控：refreshAll 统一刷新入口 + init 初始化 + 事件绑定
    └── pages/          # 各模块渲染与动作（全局函数，classic script 共享作用域）
        ├── today.js    # 今日要务
        ├── todo.js     # 待办
        ├── ledger.js   # 收支
        ├── habit.js    # 习练
        ├── wisdom.js   # 心法
        └── break.js    # 破招台（匹配/辨招/落记录/复盘）
```

### 架构约定（重构要点）

- **零构建 classic script**：各 `.js` 按依赖顺序以 `<script src>` 加载，共享全局作用域，因此 `file://` 与任意静态托管都能直接运行，无需打包器。
- **单向渲染铁律**：所有渲染函数（`renderToday/renderTodos/...`）**互不调用**；统一由 `app.js` 的 `refreshAll()` 单向编排。事件处理函数只做「改状态 → `saveState()` → `refreshAll()`」一件事，彻底避免循环依赖与 TDZ 问题。
- **关注点分离**：数据（`store`）、视图（`ui`/`charts`）、页面（`pages/*`）、主控（`app`）各司其职，便于维护与扩展。
